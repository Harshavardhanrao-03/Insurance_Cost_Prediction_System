# Insurance EDA Analysis

## 📌 Overview
This is my first data analysis project where I performed Exploratory Data Analysis (EDA) on an insurance dataset.

## 🔍 What I did
- Data Cleaning
- Data Visualization
- Identified key factors affecting insurance charges

## 📊 Key Insights
- Smoking significantly increases insurance charges
- Age and BMI impact medical costs
- Region has less effect compared to other factors

## 🛠️ Tools Used
- Python
- Pandas
- Matplotlib / Seaborn
